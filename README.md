# Bhargav Rishi — Portfolio

Pure HTML/CSS/JS portfolio.

## File structure
- `index.html` — markup, navigation, hero/profile/featured/all-projects sections.
- `style.css` — layout, theming, cards, responsive tweaks, button and chip styles.
- `main.js` — data-driven content (skills, strengths, projects, links) and DOM rendering.
- `assets/` — local images used by the header and project cards.

## Technologies
- HTML5 + vanilla CSS (custom theming, grids/flex, scroll offsets for anchors).
- JS for rendering skills, strengths, and project cards from data.
- Local assets; some projects link to external GitHub repos for details.

## Editing content
- Update skills, strengths, projects (titles, summaries, tags, links, images) and contact email in `main.js`.
- Adjust layout/colors/typography, spacing, and button styles in `style.css`.
- Swap the header photo and project thumbnails in `assets/`.

## Deploying to GitHub Pages
1. Create a repo named `USERNAME.github.io` on GitHub.
2. Copy `index.html`, `style.css`, `main.js`, and the `assets/` folder into the repo root.
3. Enable Pages (Settings → Pages → Source: Deploy from branch). It will serve at `https://USERNAME.github.io`.

No build step required.***
